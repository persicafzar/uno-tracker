📖 معرفی توابع

این سیستم شامل ۵ تابع کمکی برای دیباگ حرفه‌ای است که با تم تاریک زیبا و قابلیت‌های پیشرفته طراحی شده‌اند. هر تابع کاربرد خاص خود را دارد:

🔴

🟢

🔵

Alias کوتاه برای dump
🟣
sql()
نمایش کوئری با syntax highlighting
🟠

نمایش Call Stack کامل

⚙️ راه‌اندازی

برای استفاده از این توابع در کل پروژه، فقط کافیست یک بار فایل Helpers را لود کنید:

  1. ایجاد فایل
    // src/Core/Helpers.php // محتوای کامل فایل Helpers را در این مسیر قرار دهید
  2. لود در index.php - این خط را بعد از Autoloader اضافه کنید:
    // public/index.php require_once SRC_PATH . '/Core/Autoloader.php'; Core\Autoloader::register(); // 🆕 لود توابع کمکی require_once SRC_PATH . '/Core/Helpers.php';
  3. تمام! حالا در هر جای پروژه می‌توانید استفاده کنید:
    dd($user); dump($games, $stats); sql($query, $params);
💡 نکته

از آنجا که توابع در namespace نیستند (global)، در هر namespace ای بدون نیاز به use قابل استفاده هستند!

dd(...$vars) 🛑 STOP

مخفف "Dump and Die" - متغیرها را نمایش می‌دهد و سپس اجرای اسکریپت را متوقف می‌کند. دقیقاً مشابه Laravel.

📝 مثال ۱: دیباگ یک متغیر

public function show($id) { $user = $this->userService->getById($id); dd($user); // 🛑 اینجا کد متوقف می‌شود // ❌ این خط هرگز اجرا نمی‌شود return view('profile'); }

object(Application\Domain\User) [▼ toggle]
+ $id: integer 42
+ $nickname: string(5) "Admin"
+ $phone: string(11) "09123456789"
# $email: null
- $password: string(60) "$2y$10$..."

📝 مثال ۲: چند متغیر همزمان

dd($user, $games, $stats, ['total' => count($games)]);
dump(...$vars) 👁 CONTINUE

مانند dd() است ولی کد ادامه پیدا می‌کند. برای دیدن چند متغیر در طول اجرای برنامه عالی است.

📝 مثال: دیباگ در طول پردازش

public function store($request) { $data = $request->all(); dump($data); // 👁 نمایش و ادامه $validated = $this->validate($data); dump($validated); // 👁 بعد از ولیدیشن $result = $this->service->save($validated); dump($result); // 👁 نتیجه نهایی return redirect('/success'); // ✅ اجرا می‌شود! }
💡 کی از dump استفاده کنیم؟
  • وقتی می‌خواهید چند مرحله را پشت هم ببینید
  • برای لاگ زدن بدون توقف برنامه
  • در حلقه‌ها برای دیدن تغییرات متغیر
d(...$vars) ⚡ SHORTCUT

Alias کوتاه dump() - برای تایپ سریع‌تر در حین کدنویسی.

// این دو خط کاملاً یکسان هستند: dump($user); d($user); // حتی برای چند متغیر: d($a, $b, $c);
sql($query, $params = []) 🗄️ SQL

نمایش زیبا از کوئری SQL با syntax highlighting و لیست پارامترها.

📝 مثال: در Repository

public function getActiveUsers($limit) { $query = "SELECT id, nickname, phone FROM users WHERE status = ? AND created_at > ? ORDER BY created_at DESC LIMIT ?"; $params = ['active', '2026-01-01', $limit]; sql($query, $params); // 🗄️ نمایش کوئری return $this->db->fetchAll($query, $params); }

trace() 📍 STACK

نمایش Call Stack - مسیری که کد طی کرده تا به این نقطه برسد. عالی برای فهمیدن جریان برنامه.

🎯 ۲. دیباگ در Controller

public function login(Request $request): void { $data = $request->all(); d($data); // 👁 ببینیم چه چیزی ارسال شده $result = $this->auth->login($data); if (!$result['success']) { dd($result); // 🛑 در صورت خطا متوقف شو } }

🎯 ۳. دیباگ شرطی

// فقط اگر کاربر ادمین است دیباگ کن if ($user['role'] === 'admin') { dd($debugInfo); }

🎯 ۴. ترکیب با حلقه

foreach ($games as $i => $game) { if ($i === 0) { dump($game); // 👁 فقط اولی } }

🎯 ۵. دیباگ Exception

try { $result = riskyOperation(); } catch (Throwable $e) { dd([ 'message' => $e->getMessage(), 'file' => $e->getFile(), 'line' => $e->getLine(), 'trace' => $e->getTraceAsString(), ]); }

🛡️ نکات امنیتی

⚠️
هرگز در Production رها نکنید!

قبل از deployment، تمام فراخوانی‌های dd(), dump(), sql(), trace() را از کد حذف کنید. این توابع اطلاعات حساس را نمایش می‌دهند.

🔍 پیدا کردن توابع Debug در پروژه

# در ترمینال (Linux/Mac): grep -rn "dd(\|dump(\|sql(\|trace(" src/ --include="*.php" # در Windows PowerShell: Get-ChildItem -Path src -Recurse -Filter *.php | Select-String -Pattern "dd\(|dump\(|sql\(|trace\("

🎣 Git Pre-Commit Hook (پیشنهادی)

فایل .git/hooks/pre-commit را ایجاد کنید:

#!/bin/bash if git diff --cached | grep -E "^\+.*(dd\(|dump\(|sql\(|trace\()"; then echo "⚠️ Debug functions found! Remove before commit." exit 1 fi

🛡️ Environment-Based Debug

می‌توانید توابع را شرطی کنید:

// فقط در development اجرا شود if (getenv('APP_DEBUG')) { dd($data); }

📋 Cheat Sheet

راهنمای سریع برای استفاده روزانه:

نمایش یک متغیر و توقف
dd($user);
نمایش چند متغیر
dd($a, $b, $c);
نمایش بدون توقف
dump($data);
Alias کوتاه
d($quick);
نمایش کوئری SQL
sql($query, $params);
نمایش Call Stack
trace();
دیباگ آرایه inline
dd(['a' => 1]);
دیباگ شرطی
if($x) dd($x);
دیباگ در حلقه
foreach($a as $v) d($v);
دیباگ Exception
dd($e->getMessage());
دیباگ Request
dd($request->all());
دیباگ Session
dd($_SESSION);
