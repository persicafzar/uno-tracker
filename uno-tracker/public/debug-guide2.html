۲. معرفی توابع

۵ ابزار قدرتمند برای هر سناریو

dd

Dump & Die

نمایش و توقف کامل

متغیرها را نمایش می‌دهد و اجرای اسکریپت را متوقف می‌کند.

🛑 توقف برای دیباگ سریع
dump

Dump (Continue)

نمایش و ادامه اجرا

متغیرها را نمایش می‌دهد ولی کد ادامه پیدا می‌کند.

▶️ ادامه چندین dump پشت هم
d

Short Dump

Alias کوتاه dump

دقیقاً مانند dump() ولی کوتاه‌تر برای تایپ سریع.

⚡ سریع کمتر تایپ
sql

SQL Viewer

نمایش زیبای کوئری

کوئری SQL را با syntax highlighting و پارامترها نمایش می‌دهد.

🗄️ SQL بهترین برای Repository
trace

Call Stack Trace

نمایش مسیر فراخوانی توابع

نشان می‌دهد که از کجا و چه مسیری طی شده تا به این نقطه برسیم. برای رفع باگ‌های پیچیده عالی است!

📍 Call Stack دیباگ عمیق

۴. تابع dump()

public function createGame(array $data): array

    $gameName = trim($data['game_name']);

}

۵. تابع d()

Alias کوتاه برای dump() - سریع‌ترین راه برای دیباگ

❌ راه طولانی 
dump($user->getStats());
✅ راه سریع 
d($user->getStats());

💡 ایده‌آل برای:

  • دیباگ سریع در حین کدنویسی
  • وقتی زیاد از dump استفاده می‌کنید
  • نوشتن کد تمیزتر و کوتاه‌تر
  • زمانی که انگشتان خسته‌اید! 😄
🟣

public function getUser(int $userId): ?array

}

public function getUserGames(int $userId, string $status): array
{
    $query = "SELECT g.*, u.nickname as referee_name
              FROM games g
              INNER JOIN users u ON g.referee_id = u.id
              WHERE g.referee_id = ?
              AND g.status = ?
              ORDER BY g.created_at DESC
              LIMIT ?";
    
    sql($query, [$userId, $status, 10]);
    
    return $this->db->fetchAll($query, [$userId, $status, 10]);
}

۷. تابع trace()

Call Stack - مسیر فراخوانی توابع را نشان می‌دهد

public function checkGameCreation(int $userId): array

    // بررسی‌های ضدتقلب...

🛡️ مثال ۲: دیباگ سیستم ضدتقلب

📄 AntiCheatService.php 
public function checkGameCreation(int $userId): array
{
    // کوئری‌های SQL را ببینیم
    $query = "SELECT COUNT(*) as count FROM games 
              WHERE referee_id = ? 
              AND DATE(created_at) = CURDATE()";
    
    sql($query, [$userId]);
    
    $result = $this->db->fetchOne($query, [$userId]);
    dump('📊 Games today:', $result);
    
    // بررسی‌های مختلف
    $checks = [
        'ip_check' => $this->checkIP($userId),
        'rate_limit' => $this->checkRateLimit($userId),
        'account_age' => $this->checkAccountAge($userId),
    ];
    
    dump('🔍 All checks:', $checks);
    
    // در صورت نیاز به بررسی عمیق‌تر
    if ($checks['rate_limit'] === false) {
        trace(); // ببینیم از کجا آمده
    }
    
    return ['allowed' => true];
}

۹. نکات امنیتی

حتماً قبل از Deploy رعایت کنید

⚠️

هشدار مهم!

این توابع فقط برای محیط Development هستند. هرگز نباید در Production فعال باشند، زیرا:

  • اطلاعات حساس دیتابیس را به کاربر نمایش می‌دهند
  • رمزهای عبور، توکن‌ها و کلیدهای API ممکن است لو بروند
  • عملکرد برنامه را به شدت کاهش می‌دهند
  • ممکن است باعث نشت اطلاعات کاربران شود

✅ کارهای درست

  • • فقط در Localhost استفاده کنید
  • • قبل از commit همه dd() را حذف کنید
  • • از Git hooks برای جلوگیری استفاده کنید
  • • فایل Helpers.php را در production disable کنید

❌ کارهای اشتباه

  • • فراموش کردن حذف dd() قبل از deploy
  • • dump کردن پسورد یا توکن‌ها
  • • استفاده در Production
  • • commit کردن فایل با debug

🔧 Git Pre-Commit Hook

📄 .git/hooks/pre-commit 
#!/bin/bash

# جلوگیری از commit کردن debug functions
if git diff --cached | grep -E "^\+.*(dd\(|dump\(|d\(|sql\(|trace\()" > /dev/null; then
    echo "⚠️  Debug functions found! Remove them before commit."
    echo "🔍 Files with debug:"
    git diff --cached --name-only | xargs grep -l -E "(dd|dump|d|sql|trace)\("
    exit 1
fi

echo "✅ No debug functions found. Commit allowed."
exit 0
