توابع Debug

مشابه Laravel dd/dump برای دیباگ کردن سریع و زیبا

dd(...$vars)
DIE Laravel-Style

متغیرها را با فرمت زیبا نمایش می‌دهد و اجرای اسکریپت را متوقف می‌کند. برای دیباگ سریع و فوری عالی است.

dd(mixed ...$vars): void

📝 مثال‌ها:

php
// مثال ۱: نمایش یک متغیر $user = ['name' => 'Ali', 'age' => 25]; dd($user); // ❌ کد اینجا متوقف می‌شود // مثال ۲: نمایش چند متغیر همزمان $games = $gameService->getAll(); $stats = $userService->getStats(1); dd($user, $games, $stats); // مثال ۳: نمایش آرایه‌های بزرگ dd($_SERVER); dd($_SESSION);
💡
نکته
در حالت AJAX خالص، خروجی متنی ساده تولید می‌کند تا JSON خراب نشود.
dump(...$vars)
CONTINUE Non-blocking

مانند dd() عمل می‌کند ولی اجرای کد ادامه پیدا می‌کند. برای دیباگ چند نقطه‌ای بدون توقف عالی است.

dump(mixed ...$vars): void
php
dump('قبل از پردازش', $data); // کد ادامه پیدا می‌کند... $result = $service->process($data); dump('بعد از پردازش', $result); // همچنان ادامه می‌یابد ✅ return $result;
d(...$vars)
SHORTCUT

Alias کوتاه برای dump(). برای تایپ سریع‌تر.

php
d($user); // معادل dump($user) d($a, $b, $c); // چند متغیر
sql($query, $params)
SQL HIGHLIGHT

کوئری SQL را با syntax highlighting زیبا نمایش می‌دهد. پارامترها را هم جداگانه نشان می‌دهد.

sql(string $query, array $params = []): void
php
$query = "SELECT * FROM users WHERE id = ? AND status = ?"; $params = [42, 'active']; sql($query, $params); // خروجی: کوئری با رنگ‌بندی keywords، strings، numbers // + لیست پارامترها با نوع هر کدام

توابع URL و Asset

تولید URL های صحیح برای پروژه‌های با Subdirectory

ℹ️
چرا این توابع مهم هستند؟
پروژه شما در https://example.com/uno قرار دارد. اگر مستقیم از /dashboard استفاده کنید، به آدرس اشتباه می‌روید. این توابع به صورت خودکار prefix درست را اضافه می‌کنند.
url($path, $params)
ESSENTIAL

URL کامل را با در نظر گرفتن BASE_URL تولید می‌کند. پارامترهای GET را هم اضافه می‌کند.

url(string $path = '', array $params = []): string

📝 مثال‌های کاربردی:

🎯 URL ساده
url('/dashboard'); // => https://example.com/uno/dashboard
👤 URL با پارامتر
url('/users/123'); // => https://example.com/uno/users/123
🔍 URL با Query String
url('/search', [ 'q' => 'test', 'page' => 2 ]); // => .../search?q=test&page=2
🎮 URL بازی
url('/game/' . $gameId); // => https://example.com/uno/game/96

🌐 استفاده در View:

php + html
<!-- لینک در Navigation --> <a href="<?= url('/dashboard') ?>">داشبورد</a> <!-- لینک به پروفایل کاربر --> <a href="<?= url('/users/' . $user['id']) ?>"> <?= e($user['nickname']) ?> </a> <!-- فرم لاگین --> <form method="POST" action="<?= url('/login') ?>"> <!-- ... --> </form>

🎮 استفاده در Controller:

php
public function login($request): void { $result = $this->auth->login($request->all()); if ($result['success']) { redirect(url('/dashboard')); } redirect(url('/login', ['error' => 'invalid'])); }
base_url()
BASE

URL پایه پروژه را برمی‌گرداند (بدون مسیر اضافی).

php
base_url(); // => https://hamidionline.ir/uno
asset($path)
ESSENTIAL

URL فایل‌های استاتیک (CSS, JS, Images) را تولید می‌کند. به صورت خودکار /assets/ را اضافه می‌کند.

asset(string $path): string
php + html
<!-- CSS فایل‌ها --> <link rel="stylesheet" href="<?= asset('css/app.css') ?>"> <link rel="stylesheet" href="<?= asset('css/mobile.css') ?>"> <!-- JS فایل‌ها --> <script src="<?= asset('js/alpine.min.js') ?>"></script> <script src="<?= asset('js/htmx.min.js') ?>"></script> <!-- تصاویر --> <img src="<?= asset('images/logo.svg') ?>" alt="Logo"> <link rel="icon" href="<?= asset('images/favicon.ico') ?>"> <!-- فونت‌ها --> <style> @font-face { font-family: 'Vazir'; src: url('<?= asset('fonts/Vazir.woff2') ?>') format('woff2'); } </style>
current_url($withQuery)
UTILITY

URL فعلی صفحه را برمی‌گرداند (برای "بازگشت به این صفحه" یا analytics).

php
current_url(); // => https://example.com/uno/dashboard?page=2&sort=desc current_url(false); // => https://example.com/uno/dashboard (بدون query)
previous_url($fallback)
UTILITY

URL صفحه قبلی (از HTTP Referer) را برمی‌گرداند.

php
// دکمه "بازگشت" در فرم <a href="<?= previous_url('/') ?>">↩️ بازگشت</a> // ریدایرکت به صفحه قبلی بعد از عملیات redirect(previous_url('/dashboard'));

Environment و Config

خواندن متغیرهای محیطی و فایل‌های پیکربندی

env($key, $default)
LARAVEL-STYLE

متغیرهای محیطی را می‌خواند و مقادیر خاص (true, false, null) را به صورت خودکار تبدیل می‌کند.

env(string $key, mixed $default = null): mixed
مقدار در .env خروجی PHP
truetrue (boolean)
falsefalse (boolean)
nullnull
empty'' (empty string)
3306"3306" (string)
php
// خواندن متغیرهای مختلف $debug = env('APP_DEBUG', false); $dbHost = env('DB_HOST', 'localhost'); $dbPort = env('DB_PORT', '3306'); $appName = env('APP_NAME', 'UNO Tracker');
config($key, $default)
LARAVEL-STYLE

تنظیمات را از فایل‌های config/ می‌خواند با syntax نقطه‌ای (dot notation).

config(string $key, mixed $default = null): mixed
php
// خواندن از config/app.php config('app.name'); // => 'UNO Tracker' config('app.version', '1.0.0'); config('app.super_admin_id'); // => 1 // خواندن از config/database.php config('database.host', 'localhost'); config('database.name'); config('database.username'); // خواندن از config/melipayamak.php config('melipayamak.username'); config('melipayamak.test_mode', false);
⚠️
ساختار فایل‌ها
فایل‌های config باید آرایه‌ای از key/value برگردانند:
// config/app.php return [ 'name' => 'UNO Tracker', 'version' => '1.0.0', 'super_admin_id' => 1, ];

توابع امنیتی

محافظت در برابر XSS و CSRF

e($value)
XSS-PROTECTION

Alias کوتاه برای htmlspecialchars(). از حملات XSS جلوگیری می‌کند.

e(mixed $value): string
php + html
// ❌ خطرناک - کاربر می‌تواند script تزریق کند <input value="<?= $user['nickname'] ?>"> // ✅ امن - escape می‌شود <input value="<?= e($user['nickname']) ?>"> // استفاده در همه جا <h1><?= e($title) ?></h1> <p><?= e($description) ?></p> <span><?= e($user['bio']) ?></span>
🚨
قانون طلایی
همیشه هنگام خروجی گرفتن داده‌های کاربر از e() استفاده کنید. فقط در موارد خاصی مثل HTML تولیدشده توسط سیستم، آن را استفاده نکنید.
csrf_token() / csrf_field()
CSRF-PROTECTION

توکن CSRF برای محافظت از فرم‌ها در برابر حملات Cross-Site Request Forgery.

csrf_token(): string
csrf_field(): string
php + html
// گرفتن فقط توکن $token = csrf_token(); // => "a3f5b2c9..." (64 hex characters) // استفاده در فرم (روش آسان) <form method="POST" action="<?= url('/login') ?>"> <?= csrf_field() ?> <input type="text" name="username"> <input type="password" name="password"> <button type="submit">ورود</button> </form> // خروجی csrf_field(): // <input type="hidden" name="_csrf_token" value="a3f5b2c9..."> // استفاده در AJAX <script> const token = '<?= csrf_token() ?>'; fetch('<?= url('/api/action') ?>', { method: 'POST', headers: { 'X-CSRF-Token': token } }); </script>

توابع Utility

توابع کمکی برای کنترل جریان و کارهای روزمره

redirect($url, $code)
FLOW-CONTROL

ریدایرکت به URL دیگر با کد HTTP قابل تنظیم.

php
// ریدایرکت عادی (302) redirect(url('/dashboard')); // ریدایرکت دائمی (301) redirect(url('/new-page'), 301); // ریدایرکت با پارامتر redirect(url('/login', ['error' => 'expired']));
abort($code, $message)
ERROR

توقف با HTTP Error. برای نمایش صفحات خطا.

php
public function show($id) { $user = $this->userService->find($id); if (!$user) { abort(404, 'کاربر یافت نشد'); } if (!$user['is_public']) { abort(403, 'دسترسی غیرمجاز'); } if ($serverDown) { abort(503, 'سرویس در حال نگهداری'); } }
کد پیام پیش‌فرض کاربرد
400Bad Requestدرخواست نامعتبر
401Unauthorizedنیاز به لاگین
403Forbiddenدسترسی غیرمجاز
404Not Foundمنبع یافت نشد
500Internal Errorخطای سرور
503Unavailableسرویس در دسترس نیست
class_basename($class)
REFLECTION

نام کلاس را بدون namespace برمی‌گرداند.

php
class_basename(\Application\Services\UserService::class); // => 'UserService' $obj = new \Domain\Game(); class_basename($obj); // => 'Game'

بهترین روش‌های استفاده

نکات طلایی برای استفاده حرفه‌ای از Helpers

✅
در View ها همیشه از url() و asset() استفاده کنید

همه ورودی‌های کاربر را با e() escape کنید
حتی اگر فکر می‌کنید داده امن است، escape کنید.

قبل از commit حتماً جستجو کنید: grep -rn "dd\|dump" src/

مثل پسوردها، توکن‌ها، یا اطلاعات شخصی کاربران.
